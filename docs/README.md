# OctoAcme Project Management Docs

This README centralizes OctoAcme's project management process documents and provides a short summary of the practices we follow. Use this page as the single entry point to the process docs in this repository.

## Project management processes (summary)

- Customer-first and iterative delivery: prioritize customer value and ship small, testable increments.
- Clear ownership: every project has a named Project Manager (PM) and Product Lead.
- Data-informed decisions: define success metrics and measure outcomes.
- Regular cadence: daily standups, weekly delivery syncs, and regular demos/reviews.
- Risk-focused: maintain a risk register and escalate blockers through defined levels.
- Continuous improvement: run retrospectives and convert action items into backlog work.
